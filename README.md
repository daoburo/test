# СК «Статус» — сайт-визитка

Статический одностраничный сайт (HTML/CSS/JS без сборки). Откройте `index.html` в браузере.

- `assets/css/` — стили и подключение шрифтов (шрифты лежат локально в `assets/fonts/`)
- `assets/js/main.js` — меню и просмотр фото
- `assets/img/` — фотографии объектов (webp)
- `presentation/index.html` — презентация компании (14 слайдов 16:9) из материалов сайта; стрелки/пробел — листать, F — на весь экран, печать в PDF — по слайду на страницу
- `site-photos/` — исходные фото помещений и санатория (jpg + webp) от фотографа; в сайт идут версии из `assets/img/`
- `.claude/skills/` — скиллы веб-дизайнера и копирайтера

## Ветки

Итоговая ветка со всеми правками — `master`. Её собирает сессия-интегратор.

| Кто | Ветка | Что делает |
| --- | --- | --- |
| Интегратор | `claude/status-company-website-3nj3vh` | собирает всё в `master`, правит вёрстку и структуру |
| Веб-дизайнер | `claude/intelligent-turing-j9fz7a` | дизайн, доступность, адаптив |
| Копирайтер | `claude/wizardly-mendel-qd23jl` | тексты |
| Фотограф | `claude/epic-edison-wov379` | обработка фото |

Порядок работы: перед началом каждая сессия берёт свежий `master` (`git pull origin master`), работает в своей ветке и не трогает чужие файлы без нужды. Интегратор сливает ветки в `master` без перезаписи истории.
