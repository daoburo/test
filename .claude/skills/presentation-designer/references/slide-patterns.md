# Структуры и паттерны слайдов

Читай, когда строишь план презентации или выбираешь форму конкретного слайда.

## Содержание
- Каркасы повествования
- Паттерны слайдов
- Заметки докладчика
- Типичные ошибки

## Каркасы повествования

Выбери по цели; число слайдов подгоняй под время (~1–2 мин на слайд).

**Питч инвесторам (10–14 слайдов)**
1. Титул и одна фраза о продукте → 2. Проблема → 3. Решение → 4. Как это работает (продукт) → 5. Рынок → 6. Бизнес-модель → 7. Тракшн/метрики → 8. Конкуренты и отличие → 9. Стратегия роста → 10. Команда → 11. Финансы → 12. Запрос и на что пойдут деньги

**Предложение/продажа клиенту (8–12)**
Ситуация клиента → боль → цена бездействия → решение → доказательства (кейсы, цифры) → как внедряем (этапы) → стоимость → следующий шаг

**Отчёт о результатах (6–10)**
Главный вывод → цели и факт → ключевые драйверы → проблемы и риски → планы → что нужно от аудитории

**Обучение/лекция (по числу тем)**
Зачем это нужно → карта темы → блоки «идея → пример → упражнение» → итоги → что дальше

**Выступление на конференции (20–40 мин)**
Крючок (история/вопрос/цифра) → тезис → 3 главные идеи с примерами → вывод → призыв к действию. Не больше трёх ключевых идей: больше аудитория не удержит.

Любой каркас заканчивается слайдом «что дальше / что нужно от вас» — не «Спасибо за внимание» и не «Вопросы?» как единственным содержанием.

## Паттерны слайдов

| Задача | Паттерн | Как собрать |
|---|---|---|
| Открыть презентацию | Титул | Название-обещание, подзаголовок с аудиторией/датой, много воздуха, один образ |
| Новый раздел | Разделитель | Номер или название раздела крупно, фон акцентный, без текста сверх этого |
| Одна главная цифра | Big number | Число 80–120 pt + подпись 1 строкой + источник мелко |
| Сравнить два варианта | Две колонки | Одинаковая структура колонок, выделен рекомендуемый вариант |
| Показать динамику | Линейный график | Один выделенный ряд, подписи на линиях, вывод в заголовке |
| Объяснить процесс | Шаги | 3–5 шагов слева направо, номера, глагол в каждом шаге |
| Показать иерархию/состав | Блок-схема | Не более 3 уровней, одинаковые блоки одного уровня |
| Подтвердить кейсом | Кейс | Клиент → задача → что сделали → результат цифрой |
| Цитата отзыва | Quote | Цитата крупно, автор и должность мелко, без рамок и кавычек-ёлочек размером с лицо |
| Перечислить 3–5 пунктов | Карточки | Иконка + заголовок 2–4 слова + одна строка пояснения |
| Показать роадмап | Таймлайн | Горизонтальная ось, вехи с датами, текущая позиция выделена |
| Команда | Сетка лиц | Фото одного размера и стиля, имя, роль, одна регалия |
| Закрыть | Призыв | Одно действие, контакты, при необходимости QR |

## Заметки докладчика

Для живого выступления в заметки идут: что сказать (2–4 предложения живым языком), переход к следующему слайду, цифры и источники, которые не влезли на слайд. Слайд — это не сценарий: если докладчик читает слайд вслух, на слайде слишком много текста.

## Типичные ошибки

- **Заголовок-тема** вместо вывода → перепиши как утверждение
- **Сплошные буллеты** → схема, карточки или разбить на слайды
- **Мелкий текст ради полноты** → вынести в приложение или заметки
- **Разные стили на разных слайдах** → вернуться к мастер-слайду
- **Графики без вывода** → добавить акцент на нужном ряде и вывод в заголовок
- **Стоковые картинки без смысла** → заменить схемой, цифрой или убрать
- **Анимации ради анимаций** → оставить только пошаговое появление, если оно помогает рассказу
- **Нет призыва к действию** → добавить финальный слайд с конкретным следующим шагом
