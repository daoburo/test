# Чек-лист перед сдачей

## Доступность
- [ ] Один `h1`, заголовки идут по порядку
- [ ] Контраст текста ≥ 4.5:1 (крупного ≥ 3:1), контраст UI-элементов ≥ 3:1
- [ ] Виден `:focus-visible` у всех интерактивных элементов, Tab-порядок логичен
- [ ] У изображений осмысленный `alt` (декоративные — `alt=""`)
- [ ] У полей форм есть `label`, ошибки описаны текстом, а не только цветом
- [ ] `lang` на `<html>`, уважается `prefers-reduced-motion`

## Адаптив
- [ ] Проверено на 375 / 768 / 1280 px, нет горизонтального скролла
- [ ] Цели нажатия ≥ 44×44 px
- [ ] Текст читаем без зума, строки 60–75 знаков

## Производительность
- [ ] Изображения с `width/height`, ниже первого экрана — `loading="lazy"`
- [ ] Шрифты: `font-display: swap`, ≤ 2 семейств
- [ ] Нет лишних библиотек и неиспользуемого CSS/JS

## Согласованность
- [ ] Все цвета, размеры и отступы берутся из токенов
- [ ] Одинаковые элементы выглядят и ведут себя одинаково
- [ ] Есть состояния: hover, active, disabled, загрузка, пусто, ошибка

## SEO и метаданные
- [ ] `<title>`, `meta description`, `viewport`, Open Graph
- [ ] Семантические ландмарки (`header`, `nav`, `main`, `footer`)
